# GeraStore Website

Новая оболочка сайта GeraStore на основе исходного проекта.

## Что уже сделано

- Liquid Glass UI.
- Темная система GeraStore.
- Розовый и бирюзовый акценты.
- Адаптивная верстка.
- Каталог IPA.
- Поиск.
- Фильтр по категориям.
- Блок последних обновлений.
- Кнопка копирования URL репозитория.
- Hero с видео и автоматическим fallback на статичный poster.
- Отключение тяжелого видео при Save-Data.
- `prefers-reduced-motion`.
- Готовая точка подключения данных GeraStore.

## Видео

Положите фирменный ролик сюда:

`assets/video/gerastore-hero.mp4`

Если файла нет, сайт автоматически показывает статичный фон.

## Данные

Сайт сначала пытается получить данные из:

`https://raw.githubusercontent.com/gkuhtov/GeraStore/main/repo.json`

Если это не удалось, используется:

`data/apps.json`

Структура нормализуется в `assets/js/gerastore.js`.

## Важно

Перед публикацией нужно заменить демо-данные `data/apps.json` на актуальные данные GeraStore и проверить фактический URL репозитория для GBox.
