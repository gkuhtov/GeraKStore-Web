# GeraKStore Web

Веб-версия каталога GeraKStore.

Здесь всё собрано в одном месте, чтобы потом самим не бегать по десяти ссылкам.

## Что здесь есть

- 🔎 Поиск приложений
- 📂 Категории
- 📦 Каталог
- 🔄 Последние обновления
- 📱 Адаптация под телефон и компьютер
- 🎬 Атмосферный главный экран
- 🔗 Быстрый переход к нужным разделам

## Зачем он нужен

Store остаётся основным каталогом, а Web даёт ему нормальное место в интернете.

Красиво, удобно и пока ничего не потерялось.

## Связь с экосистемой

- [GeraKStore](https://github.com/gkuhtov/GeraKStore) - основной каталог
- [GeraKStore-Manager](https://github.com/gkuhtov/GeraKStore-Manager) - управление каталогом
- [GeraKStore-Welcome](https://github.com/gkuhtov/GeraKStore-Welcome) - welcome-экран
