## ✦ Экосистема GeraKStore

```text
GeraKStore
├── Store       • каталог приложений
├── Manager     • управление каталогом
├── Web         • веб-каталог
└── Welcome     • приветственный экран
```

## 🌐 Web

GeraKStore Web превращает каталог приложений в современное веб-пространство.

- 🔎 Поиск приложений
- 📂 Категории
- 📦 Каталог IPA
- 🔄 Последние обновления
- 🎬 Атмосферный главный экран
- 📱 Адаптация под разные устройства
- 💎 Стиль Liquid Glass
