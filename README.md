## ✦ Добро пожаловать

**GeraKStore Web** - это современная веб-страница GeraKStore, созданная для удобного просмотра каталога приложений.

Здесь всё собрано в одном месте: приложения, категории, поиск, обновления и фирменная атмосфера GeraKStore.

---

## 💎 Дизайн

Сайт сочетает тёмную визуальную основу, мягкое свечение и эффект **Liquid Glass**.

Интерфейс вдохновлён современным стилем iOS: аккуратные карточки, плавные элементы и небольшие анимации создают ощущение цельного и живого пространства.
